# AsterBot

Production-ready modular Node.js crypto bot supporting paper/live trading, adaptive AI, risk management, alerts, portfolio tracking, backtesting, and live dashboard.

## Quick start

```bash
cd asterBot
npm install
npm start
```

Open `http://localhost:3000`.

## Backtest

```bash
npm run backtest
```

## Notes

- Configure exchange and alert credentials in `.env`.
- Runtime config is in `config.json` with hot reload.
